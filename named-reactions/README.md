# Named reaction catalogues · 人名反应目录

[Jie Jack Li](Li.md) · [László Kürti and Barbara Czakó](Kurti-Czako.md) · [Machine-readable catalogue](catalog.json)

Each entry names a reaction family and gives its printed page. A linked UMR program encodes a particular substrate, electron movements and declared assumptions. Its recorded outcome states how much of that path the executor can replay. The evidence level on each event distinguishes a textbook observation, an inference and a proposed completion.

目录按反应家族列出书页。点开原生程序可以看到该实例的底物、电子动作和所声明的机理假设。目录分别记录可回放的序列、部分路径、仅报告的净转化及书目记录。事件上的证据等级区分教材观察、推断及为衔接路径提出的步骤。

Page numbers locate the named reaction in the book. Individual event records identify inferences and proposed steps as the UMR authors’ interpretations. Source DOIs are retained where provided.

书页用于定位反应家族。每个事件的证据等级标明哪些步骤由 UMR 记录者推断或提出；有 DOI 的来源同时列出。
